# Лабораторная работа №9 - Приложение «Cities Catalog»
Приложение для просмотра информации о городах мира, разработанное в рамках лабораторной работы №9. Реализовано с использованием Jetpack Compose.

ФИО: Старцева Полина Сергеевна

Группа: ИСП-231
## Функциональность
- Просмотр информации о городах мира:
  - Изображение города
  - Название города
  - Описание города
- Навигация между городами с помощью кнопок:
  - **"Предыдущий"** — переход к предыдущему городу
  - **"Следующий"** — переход к следующему городу
- **Интеллектуальная навигация:**
  - Кнопка "Предыдущий" неактивна на первом городе
  - Кнопка "Следующий" неактивна на последнем городе
- Данные загружаются из источника данных `Datasource`
## Используемые элементы Compose
- ``Column`` — вертикальное расположение элементов (изображение, текст, кнопки)
- ``Row`` — горизонтальное расположение кнопок навигации
- ``Image`` — отображение изображений городов (через `painterResource`)
- ``Text`` — вывод названия и описания города (через `stringResource`)
- ``Button`` — кнопки навигации с параметром `enabled`
- ``MaterialTheme.typography`` — использование встроенных стилей текста
## Логика работы
### Управление состоянием
```kotlin
var currentIndex by remember { mutableStateOf(0) }
```
- ``remember`` сохраняет состояние при рекомпозиции
- ``mutableStateOf`` отслеживает изменения индекса и обновляет UI
### Навигация с защитой от выхода за границы
```kotlin
Button(
    onClick = {
        if (currentIndex > 0) {
            currentIndex--
        }
    },
    enabled = currentIndex > 0
) {
    Text("Предыдущий")
}

Button(
    onClick = {
        if (currentIndex < datasource.cities.size - 1) {
            currentIndex++
        }
    },
    enabled = currentIndex < datasource.cities.size - 1
) {
    Text("Следующий")
}
```
### Безопасное получение текущего города
```kotlin
val currentCity = datasource.cities.getOrNull(currentIndex)
currentCity?.let { city ->
    // Отображение данных города
}
```
- ``getOrNull()`` предотвращает выход за границы списка
- ``?.let выполняет`` код только если город существует
